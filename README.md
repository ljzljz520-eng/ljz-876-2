# 驾校科目一模拟考试系统

一个从零实现的科目一刷题/模考平台，零第三方依赖（Node.js 原生 HTTP + JSON 文件存储）。

## 功能一览

### 学员端（移动端 H5，适合碎片时间刷题）
- **按章节练题**：四大章节，覆盖率/正确率进度条，可随时中断、继续
- **即时讲解**：答完立刻显示对错 + **讲人话的解析** + 法规依据，错题自动收入错题本
- **错题重做**：只刷未攻克错题，做对自动移出错题本，也可手动标记"已掌握"
- **全真模拟**：现行题库随机抽 100 题、45 分钟倒计时、90 分及格；
  考试中不显示答案（防泄题），交卷后逐题回顾解析；超时自动交卷，未答按错计但不入错题本
- **个人中心**：累计答题、章节掌握度、模拟考历史

### 教练后台（桌面端）
- 学员总览：最近模拟分、及格状态、未攻克错题数
- **个人易错法规聚合**：按知识点标签统计踩坑次数和错误率（如"记分/高速/事故急救"）
- **预约考试建议规则引擎**：根据最近模拟分、近两次均分、开放错题数、章节覆盖率给出
  "建议约考 / 可以约但再稳一稳 / 临界冲刺 / 暂不建议 / 未参加模拟"五档建议，全部附人话说理和行动清单
- 全班普遍易错法规 TOP 榜（多少人踩坑）、模拟成绩柱状图、学员错题明细
- 题库版本切换（演示更新发布流程）

### 题库更新后旧错题仍可回看（核心设计）
- 题目以 `qcode + 版本` 维度存储，每题属于一个题库版本
- **学员每次答错，系统保存当时题目的完整快照**（题干/选项/答案/解析/法规/版本号）
- 题库更新后：
  - 答案变更题（如 Q004 开车打电话 2022 新规 2 分→3 分）：错题本标注"法规已更新"，旧快照可回看
  - 新增题（如 Q026 学法减分、Q102 快速路车道）：旧版练不到，新版自动出现
  - 已淘汰题（如 Q105 60 岁体检→2022 改为 70 岁）：标注"旧版已淘汰"，旧题仍能回看、按旧答案重做判分

## 快速开始

```bash
npm start            # 或 node server/index.js
```
- 学员端（手机/移动视图效果最佳）：http://localhost:3000/
- 教练后台：http://localhost:3000/coach

重新生成演示数据：`npm run seed`（会清空 data/db.json 重建）

## 题库
现行 2022 版 104 题 + 2021 旧版 103 题，覆盖：
道路交通安全法律法规、交通信号、安全文明驾驶、驾驶操作基础。
解析均为口语化表达并标注法规出处（《道路交通安全法》《实施条例》《记分管理办法》等）。

## 主要 API
- `POST /api/login`
- `GET  /api/student/home`、`GET /api/chapters`、`GET /api/wrong-book`
- `POST /api/sessions`（kind: chapter/wrong/mock）
- `POST /api/sessions/:id/answers`、`POST /api/sessions/:id/finish`、`GET /api/sessions/:id`
- `POST /api/wrong-book/:id/master`
- `GET  /api/coach/overview`、`GET /api/coach/students/:id`、`GET /api/coach/students/:id/wrong`
- `GET  /api/admin/versions`、`POST /api/admin/activate-version`

## 目录结构
```
server/
  index.js           HTTP 服务 + 路由 + 会话/判分
  db.js              零依赖 JSON 文件数据库
  services.js        统计聚合 / 易错标签 / 预约建议规则引擎
  seed/questions.js  题库（题干/选项/解析/法规/标签/版本差异）
  seed/run-seed.js   演示数据初始化
public/
  student/           学员端移动 SPA（原生 JS + Hash 路由）
  coach/             教练后台 SPA
data/db.json         运行时数据（首次 seed 后生成）
```
